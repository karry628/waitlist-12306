# 模拟12306车票候补模块（基础版）

## 项目简介

本项目模拟 12306 车票候补功能：旅客没买到票时可以提交候补订单，系统按提交时间先后顺序排队（**先进先出 FIFO**）。当有退票/放票产生余票时，系统从队头开始依次为候补用户分配车票，**先候补先出票**。

## 数据结构

- 使用 **队列（Queue / FIFO）** 作为核心数据结构
- Python 实现基于 `collections.deque`（双端队列，入队/出队均为 O(1)）
- 队尾 = 新订单入队位置；队头 = 余票发放时优先出票位置

## 订单信息

每条候补订单包含：
| 字段 | 说明 |
|------|------|
| 订单号 | 系统自动生成，格式 `WX1001` 递增 |
| 旅客姓名 | 用户输入 |
| 身份证号 | 18位，带格式校验 |
| 所需票数 | 默认1张，可自定义 |
| 下单时间 | 自动记录 |

## 系统功能

### 基础功能（作业要求）
1. **新增候补订单**：将订单加入队列尾部（入队）
2. **余票发放**：输入释放余票数量 k，从队头依次处理，满足则出队出票，不满足则等待下次放票
3. **余票为0时**：队列不为空则继续等待，新订单继续入队尾
4. **退出程序**

### 增强功能（自行扩展）
5. **查看候补队列**：实时显示队列中所有订单及排队位置
6. **取消候补订单**：按订单号取消并从队列移除
7. **身份证格式校验**：18位格式校验
8. **隐私保护**：显示时身份证号中间打码

## 算法思路

```
入队（新候补）：
    deque.append(order)          →  O(1)

出队（余票发放）：
    while 剩余余票 > 0 and 队列非空:
        看队首 order = deque[0]
        if order.tickets <= 剩余余票:
            deque.popleft()      →  O(1)，出票成功
            剩余余票 -= order.tickets
        else:
            break                →  余票不足，停止发放
```
